# Original demo illustrations

All SVG files in this directory were authored locally for this starter as geometric vector illustrations. They do not depict real animals and contain no photographs, downloaded assets, embedded raster images, fonts, external references, or original-shelter metadata.

- `paws-mark.svg`: original paw mark.
- `*-portrait.svg`, `*-play.svg`: original fictional dog character illustrations, with two views per character.
- Reuse is covered by the starter's root LICENSE; see the root provenance notice for the inherited application code.

Replace these assets and update `src/config/shelter.ts` / `src/data/demoDogs.ts` when customizing a shelter. Never copy animal or person photos without permission.
