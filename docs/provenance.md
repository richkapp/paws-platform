# Code and asset provenance

This starter derives from the earlier Paws Platform application by Richard Kapp and Paws Platform contributors, originally presented as the Build to Own Club animal-shelter website template. Reusable application and scoring code has been retained; operational history, private environments, historical data exports, real animal records and third-party photos have not been included.

The earlier source README explicitly stated “MIT — fork it, customize it, ship it.” No standalone `LICENSE` file was tracked in the exported source. The root MIT file records that stated code license and generic contributor attribution; it is **not** evidence of a previously verified standalone notice or permission to redistribute any unrelated real shelter assets. No separate original copyright notice was found in the allowlisted source. Dependency packages retain their own licenses via their distributions and are not relicensed here.

The fictional dataset and local SVG illustrations were newly authored for this starter. See `ASSETS-LICENSE.md` for asset scope. If you add real photos, logos, personal data or third-party content, verify permission separately and document the source and terms before publication. The MIT code license does not supply missing photo/model/privacy rights.
